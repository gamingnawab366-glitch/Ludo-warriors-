LUDO WARRIORS — ANDROID RELEASE PREP
====================================

यह पैकेज Android export के लिए तैयार किया गया Godot project है:
- App name: Ludo Warriors
- Package ID: com.ludowarriors.game
- Version: 1.0.0 (version code 1)
- Portrait orientation
- Android app icon included (icon.png)
- Android export preset included (export_presets.cfg)

- इस environment में Godot Android export templates, Android SDK और signing keystore उपलब्ध नहीं हैं;
  इसलिए APK/AAB यहाँ से compile/sign नहीं किया गया है।
- Play Store पर डालने से पहले Godot में project run-test, Android device test,
  release keystore signing, AAB export और Play Console policy/forms पूरे करने होंगे।

Project files:
